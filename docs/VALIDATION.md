# v0.2 本地验收记录

验证日期：2026-11-25。使用本地 Cloudflare Worker、智谱 GLM-4.7 与火山 `volc.seedasr.auc`。尚未部署网站。

## 真实视频

使用另一段真实视频：[MIT OCW · What is Computation?](https://www.youtube.com/watch?v=nykOeWgQcHM)，讲者 Dr. Ana Bell，约43分钟。

- 本次 YouTube 字幕抓取受访问限制，实际使用同一视频的 MIT 发布方在线字幕；页面显示真实来源。没有将此次结果归为 YouTube 直接抓取成功。
- 读取887条字幕、34,012字符，生成五章节中文文章，包含28个不同的有效原文编号。
- 真实流式增量、章节5W1H及缓存命中通过；原文未提到的时间和地点显示“未明确提及”。
- 导入一处人为修改的字幕，验证差异、人工确认、保存和创建新文章；这部分属于受控校对测试，不冒充真实ASR。
- 测试发现模型会忽略精确章节数，已改为保留原文段落的纯函数重组，并以单元测试覆盖。

## 真实火山 ASR

新开通的密钥提交官方6.3秒示例音频并查询成功。随后测试真实MIT音轨90–180秒的90秒片段（来源与许可见音频fixture说明）。

- 异步识别完成，约67秒、5次后台查询；单次观察不代表性能承诺。
- 官方字幕与ASR按时间轴对齐为6组，其中5组有文字差异，没有数字差异。多数涉及口语、停顿与切句；差异组数不是错误率。
- 人工确认后保存，再用确认来源生成三章节新文章，状态complete、6个不同的原文编号，约14秒；旧文章正文未改变。
- 没有据此宣称ASR更准确，也没有进行校准后的WER/CER评测。产品保留原文、回听及手动修订入口。
- GitHub raw和jsDelivr音频链接本机能访问，但火山下载失败（45000006）。改用临时存储的直接对象下载链接后成功。不能把“本机能下载”当作“服务商可下载”。

## 工程与交互验证

- 最终检查通过：70项单元测试、TypeScript严格检查、Prettier、生产构建和Worker部署dry-run。
- 单元测试覆盖字幕解析、SSE分片、引用、5W1H协议、时间轴对齐、数字/否定差异、版本冲突、任务取消/替换竞态、音频URL边界、章节重组与文本差异。
- TypeScript严格检查、Prettier、生产构建及Worker部署dry-run作为发布前检查；dry-run不会部署网站。
- 浏览器检查桌面和390px移动视口：文章引用定位、原文搜索、总结引用、手动修订、批量确认、保存校对、Escape关闭与焦点恢复。
- 实测遇到过模型断流、引用遗漏和音频下载失败。中断保留正文；引用遗漏通过只补真实编号的逐段结构化请求处理，失败不标记完成。ASR查询可继续同一个任务，不重复提交。

## 当前边界

- 没有本地音频上传、YouTube音轨下载或转码；ASR需要服务商可下载的同一音频公网HTTPS直链。
- 官方字幕降级映射只覆盖经过核对的MIT示例；其他视频受限时应导入字幕。
- Gemini适配器只有协议测试，尚未进行真实账号联调；本轮按用户授权使用智谱，提交前需向出题方说明。
- 引用编号存在性校验不等同于语义事实核查。字数要求也不是严格保证。
- 线上出口、存储与鉴权仍需部署后验证。部署等待用户体验确认。
