# 使用 Recast

打开[线上站点](https://recast-xvc.mixuechu.workers.dev)，输入维护者提供的访问码。网页运行在云端，不需要本机启动服务。

1. 粘贴带字幕的公开视频链接，例如 [3Blue1Brown · But what is a neural network?](https://www.youtube.com/watch?v=aircAruvnKk)。
2. 可填写要求：“面向初学者，用中文整理为三个章节，约1000字，解释关键概念，保留原讲者的论证。”
3. 点击生成，文章会逐段出现。引用与结构检查通过后标记完成；中途可以停止，已生成内容会保留。
4. 点击章节标题旁的 **5W1H**，查看结构化总结。原文未明确说明的信息显示“未明确提及”。
5. 点击段落中的“原文”或“查看原文依据”，搜索字幕、核对引用；点击时间点可跳回 YouTube。
6. 可复制或导出文章。左侧“最近整理”可恢复24小时内的记录；删除会移除服务端文章，24小时后记录自动过期。

同一视频24小时内再次整理会复用字幕，文章按本次要求重新生成；旧文章不会被改写。5W1H同章结果也会缓存。

YouTube 无现有字幕、视频受限或服务额度不足时，页面会提示原因。可稍后重试，或在“粘贴字幕”中导入 SRT、VTT、纯文本。纯文本没有时间轴，页面不会虚构时间。应用不再提供 ASR 或音频上传。

首页真实课程与其他视频使用同一条读取流程；原创示例会明确标注，不是指定视频的真实字幕。

本地开发请按 [README](../README.md) 配置后运行 `npm run dev`。默认端口8787，若被占用可先构建，再运行 `npx wrangler dev --port 8788`。修改服务端密钥后重启；不要关闭属于其他项目的进程。
